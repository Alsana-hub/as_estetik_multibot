# As_estetik MAX Bot

MAX-бот для частной практики As_estetik.

Бот помогает клиентам ознакомиться с услугами, ценами, выбрать подходящий вид массажа, записаться онлайн и связаться со специалистом.

## Возможности

- каталог услуг
- цены и длительность процедур
- помощь в выборе услуги
- онлайн-запись через DIKIDI
- подарочные сертификаты и абонементы
- контакты
- информация о специалисте
- информация перед визитом
- связь через MAX
- переход в канал As_estetik
- работа через MAX Bot API
- поддержка webhook
- резервный режим long polling

## Технологии

- Python
- asyncio
- aiohttp
- python-dotenv
- MAX Bot API

## Структура проекта

## Переменные окружения

Для локального запуска необходимо создать файл `.env`.

Пример:

```env
MAX_BOT_TOKEN=
MAX_USE_WEBHOOK=false
MAX_WEBHOOK_SECRET=
MAX_WEBHOOK_URL=
```

`MAX_BOT_TOKEN` и `MAX_WEBHOOK_SECRET` не должны храниться в репозитории.

## Режимы работы

Бот поддерживает два режима получения событий от MAX.

### Long polling

Используется как резервный режим.

```env
MAX_USE_WEBHOOK=false
```

В этом режиме бот получает события через `/updates`.

### Webhook

Используется для работы на сервере.

```env
MAX_USE_WEBHOOK=true
```

События MAX принимаются по маршруту:

```text
/max/webhook
```

Webhook защищён секретом `MAX_WEBHOOK_SECRET`.

## Локальный запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить бота:

```bash
python bot.py
```

## Развёртывание

Проект подготовлен для размещения на Amvera.

Для серверной версии используется webhook и переменная `PORT`, предоставляемая платформой.
